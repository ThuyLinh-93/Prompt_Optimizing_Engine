# Demo Script (3~5분)

## 1. 소개 (30초)
- 본 프로젝트는 AI Agent 기반 품질 개선 자동화 엔진입니다.
- 핵심은 Agent 개발 + Spec 기반 바이브코딩 + PL 오케스트레이션입니다.

## 2. 흐름 설명 (1분)
- 입력 4종 로드
- Review 평가
- 미달 시 Optimizer/Summary 루프
- 조건 충족 시 최종 3파일 저장

## 3. 실행 시연 (2분)
- Start 실행
- Stop? false -> 루프 1회 확인
- Stop? true -> final 파일 3개 생성 확인

## 4. 마무리 (30초)
- 업무 적용 가능한 형태로 완성
- 실제 AIrepoto 운영 연동이 다음 단계
